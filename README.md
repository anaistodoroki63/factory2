# Satis2D - Jeu en ligne

Ce projet est un jeu de type usine / gestion. Il peut être déployé comme site statique pour être partagé sans téléchargement.

## Fichiers
- `index.html` : page web principale
- `style.css` : styles du site
- `game.js` : logique du jeu

## Déploiement en ligne
1. Crée un dépôt GitHub dans lequel tu mets ces fichiers.
2. Active GitHub Pages dans les paramètres du dépôt.
3. Le site sera disponible via une URL du type `https://<ton-nom>.github.io/<ton-repo>`.

## Alternatives rapides
- Netlify : glisse le dossier dans Netlify et obtiens un lien partageable.
- Vercel : connecte le dépôt GitHub et déploie automatiquement.

## Utilisation
- Clique sur un bâtiment.
- Clique sur la grille pour le placer.
- Utilise `Supprimer` pour retirer un bâtiment.
- Utilise `Pause` pour mettre le jeu en pause.
